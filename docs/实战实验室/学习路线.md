## 三轮练习

1. 第一轮只运行。先用标准库测试，再装锁定 SDK 跑完整测试与 MCP。记下解释器、依赖和跳过数。
2. 第二轮只改变一个条件。知识库撤权、Agent 耗尽预算、MCP 输入非法表达式，观察输出是否仍满足原断言。
3. 第三轮口述设计。每题用两分钟讲“需求、方案、代价、何时失败、如何验证”；对照 [40 题答案](./场景题40.md)，不要背无条件结论。

想快速回顾概念可看 [Top50](../工具箱/TOP50-高频题.md)；想按项目排查可看 [调试场景](../工具箱/DEBUG-SCENARIOS.md)。[公司经验笔记](../工具箱/COMPANY-MAP.md) 仅用于提出待核实的问题，岗位说明与实际招聘沟通优先。
